# The order 360X's loader asks for its files, first request first, over the boot, the
# front end and the loads of Missions 1 to 9 (a file the game asks for again keeps
# its first place). tools/x360_dat.py --order puts the files of 360X.DAT in this order,
# so each load reads mostly neighbouring sectors. One base name a line, as the game's
# FILES.C looks them up. Files not named here (never requested by any mission) follow.
#
# Made from the debug console's "Loading File ..." and "Streaming File ..." lines of
# nine disc runs (the heap gate's presses, one run a mission): for each run in turn,
# each name not seen before is appended, without its folder (names are unique across
# folders, x360_dat.py checks). One exception: the sound bank (OPTIONS.VH, OPTPA.SEQ,
# OPTPB.SEQ, OPTIONS.VB) sits where Mission 1's load ends, not at the boot, because
# every mission loads it last and the boot loads it once.
# CHLINK.PSX and .SPR (the chain weapon's shot, which the restoration loads since the list was made,
# LOADDATA.C) sit where every mission asks for them, after S_SPFIRE: unlisted, they were at the
# DAT's end, two long seeks in each mission load (Mission 1 CD log, 2026-11-27).
