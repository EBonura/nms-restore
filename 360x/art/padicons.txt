# 360X pad button icons (new work, owner's request 2026-11-22: "real pictures of the controller
# buttons" on the pause screen). Drawn for this game, in the style of its medium font: 1-pixel
# strokes with a dark outline, glyphs on rows 4 to 14 of a 16-row cell.
#
# tools/x360_padicons.py turns this file into the header the game includes (360x/build.sh runs it).
# The game writes the icons into the unused bottom quarter of its font page (FONTS.TIM rows 192 to
# 255) before that page goes to VRAM, and draws them with their own palette (below).
#
# Palette: one character per colour index, then r g b (0 to 255). Index 0 is transparent.
palette
. 0 0 0 0
k 1 32 32 32
w 2 248 248 248
b 3 64 64 64
g 4 72 216 176
r 5 248 96 104
u 6 120 168 248
p 7 240 144 216
l 8 152 152 152
