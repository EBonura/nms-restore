Game
----
	- Eight direction scroller
	
	- Dynamic VRAM manager for sprites and CLUTS
	
	- 16 color compressed sprites

	- CD Audio implemented. Will put in SFX when I get some (!)

	- Particles now use fixed point arithmetic and lookup tables from SGL.
	  All particle processing carried out by slave CPU	  	
	
	- Craft dynamics in fixed point arithmetic and controlled by
          slave CPU
	
	- Basics of firing implemented ; need to convert some of the
	  calculations to fixed point look-up and implement new weapons
	
	- Background collision (needs to be made pixel perfect for craft)
	
	- In game functions done for GAMMA, CD and SFX volume. Will add more
	  as I think of them
	
	- Current logic interpreter from PC fully implemented
	
	- CD file system code (from Offensive)

	- Panel GFX and scoring

	- Backup RAM done for system memory and cartridge

Miscellaneous Issues

Memory
------
	This is running VERY LOW at the moment. I have 3K left! Overlays
should get me some memory back and Phils new sprite object manager will get
me a little bit more back. I need to change things to be as level dependant
as possible. This will be one of the big headaches.

Grabber
-------
	Certain things are being held back because the grabber has an
annoying limitation - it cannot grab sprites wider or higher than 128.
I will be writing a grabber of my own soon which will take up some of
my time.


Convertors

	Written many of these to convert PC text files into binary
