# QD Up's scene images (R2), read by tools/scenes.py (format in its header). RESTORE: PLATFORM.
# docs/DECISIONS.md, "Scene images": the base keeps every variable (each object's .data and .bss,
# NMS's GLOBALS.H globals) and all code a match can reach; an image changes only where NMS's flow
# already loads from the CD: the title (FRONT.TGA) and the table (PLEASE WAIT).
#
# The region is as large as the largest image, so the RAM the split gives back is the smaller of
# FRONT and TABLE: TABLE holds the game's own loop (game.o, Run_Game), at least as large as FRONT.
# The 2D and 3D views, the physics, rules and AI stay in the base, so pause, undo, replay, the end of
# a frame and the L2+R2 view switch never wait on the disc.

region 0x1000 0x000

# Boot-only code, not a scene (PLAN.md "Splash: one mechanism"): the splash (the SDK's, with the PSX Archive credit). POOL.C calls it first thing, before
# grab_available_ram_for_us takes and clears the heap it runs in. The EXE carries it: no read before the splash.
image 1 BOOT boot
layer .boot_only .boot_only.* .text.PsxSplash .text.*psx_splash* .rodata.*psx_splash*
entry PsxSplash

# The front end (the EXE carries it too, so the title needs no extra read): the title picture, the option screen with its icons and models, the 2D or 3D choice,
# PLEASE WAIT. PSX.C, COMMON.C, MENU.C and GFX.C are built with -ffunction-sections in the disc build
# so their front-end functions can come here; their in-game functions and all their data stay.
image 2 FRONT preload
objects new_viewchoice models new_baizeicon
functions psx draw_title_screen Show_Loading LoadAllWrapperGfx DrawBackdrop DrawIcons DrawInsideBall DrawNumber8 DrawNumber81 DrawReflect DrawReflect1 DrawTitle
functions common AnimateCurrentIcon DecompAllIcons DecompIcon DrawOptionsScreen LoadIconFiles LoadModelFiles SetupAllIcons UpdateIcon
functions menu Enter_Main_Options DecodePad bit2raw
functions gfx LoadTGA
entry draw_title_screen Enter_Main_Options Show_Loading

# The table: the game's loop. Everything it calls stays in the base.
image 3 TABLE
objects game
entry Run_Game
